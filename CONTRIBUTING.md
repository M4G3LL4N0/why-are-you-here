# Contributing

Thanks for taking an interest in this project.

This repository is intentionally small, but the same standards apply as on larger Noaerth projects:

- keep changes focused and easy to review
- explain the problem before the implementation
- include verification steps when behavior changes
- prefer reproducible examples over screenshots alone
- do not commit credentials, private data, or generated dependency folders

## Pull requests

Use a branch, open a pull request, describe what changed and why, and include any relevant test or verification notes.

## Issues

Use issues for reproducible bugs, concrete improvements, or questions that would benefit future contributors.
